# 🤖 ربات دانلودر تلگرام

ربات کامل دانلود از یوتیوب، اینستاگرام، تیک‌تاک و توییتر/X با انتخاب کیفیت، دانلود صدا (MP3)، محدودیت روزانه و پنل ادمین.

---

## 📁 فایل‌های پروژه

| فایل | توضیح |
|---|---|
| `bot.py` | کد اصلی ربات |
| `requirements.txt` | پکیج‌های پایتون موردنیاز |
| `Dockerfile` | برای اجرا روی Railway (شامل ffmpeg) |
| `railway.json` | تنظیمات دیپلوی Railway |
| `.env.example` | نمونه متغیرهای محیطی |

---

## ✅ مرحله ۱: ساخت ربات در تلگرام

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده.
2. دستور `/newbot` رو بفرست.
3. یک اسم برای ربات انتخاب کن (مثلاً: `دانلودر من`).
4. یک یوزرنیم که به `bot` ختم بشه انتخاب کن (مثلاً: `my_downloader_bot`).
5. BotFather یک **توکن** به شکل زیر بهت می‌ده — این رو جایی کپی کن:
   ```
   123456789:AAExampleTokenHere1234567890
   ```

### گرفتن آیدی عددی خودت (برای ادمین شدن)
1. به [@userinfobot](https://t.me/userinfobot) پیام بده.
2. عدد `Id` که برات می‌فرسته رو کپی کن — همین آیدی رو در `ADMIN_IDS` قرار می‌دیم.

---

## ✅ مرحله ۲: ساخت ریپازیتوری روی GitHub

1. وارد [github.com](https://github.com) شو و یک ریپازیتوری جدید (Private یا Public) بساز، مثلاً به اسم `telegram-downloader-bot`.
2. فایل‌های این پروژه (`bot.py`, `requirements.txt`, `Dockerfile`, `railway.json`, `.gitignore`) رو در اون ریپازیتوری آپلود کن. ساده‌ترین راه:
   - در صفحه ریپازیتوری روی **Add file → Upload files** کلیک کن.
   - همه فایل‌ها رو بکش و رها کن (Drag & Drop).
   - پایین صفحه روی **Commit changes** بزن.

> ⚠️ فایل `.env` را هرگز آپلود نکن — توکن رو مستقیم در Railway وارد می‌کنیم (مرحله بعد).

---

## ✅ مرحله ۳: ساخت پروژه در Railway

1. وارد [railway.app](https://railway.app) شو و با اکانت GitHub لاگین کن.
2. روی **New Project** کلیک کن.
3. گزینه **Deploy from GitHub repo** رو انتخاب کن.
4. ریپازیتوری `telegram-downloader-bot` که ساختی رو انتخاب کن.
5. Railway به‌طور خودکار `Dockerfile` رو تشخیص می‌ده و شروع به ساخت (Build) می‌کنه — فعلاً صبر کن، چون هنوز متغیرها رو نداده‌ایم ممکنه ربات بالا نیاد؛ این طبیعیه.

---

## ✅ مرحله ۴: تنظیم متغیرهای محیطی (Environment Variables)

1. داخل پروژه‌ی Railway، روی سرویسی که ساخته شده کلیک کن.
2. برو به تب **Variables**.
3. روی **New Variable** بزن و این‌ها رو یکی‌یکی اضافه کن:

| نام متغیر | مقدار |
|---|---|
| `BOT_TOKEN` | همون توکنی که از BotFather گرفتی |
| `ADMIN_IDS` | آیدی عددی خودت (اگه چندتا ادمین داری با کاما جدا کن: `111,222`) |
| `DAILY_LIMIT` | مثلاً `10` (تعداد دانلود مجاز روزانه هر کاربر) |

4. بعد از اضافه کردن متغیرها، Railway به‌طور خودکار یک **Redeploy** انجام می‌ده.

---

## ✅ مرحله ۵: بررسی اجرا شدن ربات

1. در Railway به تب **Deployments** برو و روی آخرین دیپلوی کلیک کن.
2. روی **View Logs** بزن.
3. اگه همه‌چیز درست باشه، باید این خط رو ببینی:
   ```
   Bot is starting...
   ```
4. حالا در تلگرام به ربات خودت پیام بده و `/start` رو بزن — باید پیام خوش‌آمدگویی رو ببینی 🎉

---

## 🧪 تست ربات

- یک لینک یوتیوب، اینستاگرام یا تیک‌تاک رو برای ربات بفرست.
- روی یکی از دکمه‌های کیفیت بزن.
- منتظر بمون تا فایل دانلود و برات ارسال بشه.

دستورات موجود:
- `/start` — شروع و خوش‌آمدگویی
- `/help` — راهنما
- `/stats` — آمار استفاده شخصی
- `/admin` — پنل ادمین (فقط برای آیدی‌های داخل `ADMIN_IDS`)

---

## ⚙️ نکات فنی مهم

- **حجم فایل:** تلگرام اجازه ارسال فایل بالای ~۲ گیگابایت رو نمی‌ده؛ کد به‌صورت خودکار این حالت رو تشخیص داده و به کاربر پیام مناسب می‌ده.
- **پایگاه‌داده:** از SQLite استفاده شده (`bot_database.db`) که به‌صورت خودکار ساخته می‌شه. توجه: روی Railway پلن رایگان، فایل‌سیستم پایدار نیست و ممکنه با هر ری‌استارت این فایل خالی بشه. اگه آمار درازمدت مهمه، بعداً می‌تونیم به Railway Postgres مهاجرت کنیم — کافیه بگی.
- **ffmpeg:** برای تبدیل به MP3 و ادغام صدا/تصویر لازمه؛ در Dockerfile نصب شده و نیازی به کار اضافه نداری.
- **قوانین پلتفرم‌ها:** برخی از پلتفرم‌ها (به‌خصوص اینستاگرام) گاهی محدودیت‌های نرخ درخواست (rate limit) دارن. اگه با خطا مواجه شدی، چند دقیقه صبر کن و دوباره امتحان کن.
- **به‌روزرسانی yt-dlp:** سایت‌ها گاهی ساختارشون رو تغییر می‌دن. اگه دانلودها یهو با خطا مواجه شدن، معمولاً کافیه نسخه `yt-dlp` رو در `requirements.txt` به جدیدترین نسخه آپدیت کنی و دوباره روی Railway دیپلوی کنی.
